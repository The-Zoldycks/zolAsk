# Quick start

1. Run `npm install`.
2. Copy `.env.example` to `.env.local` and add a Gemini or Groq key.
3. Run `npm run dev`, then open `http://localhost:3000`.

The interface automatically follows the system color preference. Enter an idea, select or type details, generate a prompt, then edit, copy, or refine it.

For the full configuration and architecture notes, see [README.md](./README.md).
